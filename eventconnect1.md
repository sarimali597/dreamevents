# EventConnect — A Unified Event Management Marketplace

> **My Vision:** To build a single platform where anyone planning an event — whether it's a wedding, corporate dinner, mehendi, or barat — can discover, compare, and book every service they need. No more running between vendors, no more WhatsApp haggling, no more wondering if a caterer is actually available on your date. Everything in one place, transparently.

---

## 1. What Problem Am I Solving?

Right now, if you want to plan an event in Pakistan (or anywhere in South Asia really), you have to:
- Drive to 5 different marriage halls to check availability
- Message 10 caterers on WhatsApp and wait hours for prices
- Hope the photographer you like is free on your date
- Negotiate everything blindly with no benchmarks
- Pay deposits with zero protection

For vendors, it's equally broken:
- They rely on walk-ins and word-of-mouth
- They get bombarded with "price?" messages that go nowhere
- They double-book because they manage calendars on paper
- They have no online presence except maybe an Instagram page

**EventConnect fixes both sides.**

---

## 2. The Core Idea

EventConnect is a **multi-vendor marketplace** where event service providers — marriage halls, catering centers, photographers, decorators — can list their services, manage availability, and receive bookings. Users can explore vendors by city, compare options, get instant price estimates, and book everything through one platform.

### Three Main User Types:

| Role | Who They Are | What They Do |
|------|-------------|--------------|
| **User / Event Planner** | Someone planning an event | Discovers vendors, compares prices, builds custom menus/packages, requests quotes, makes bookings |
| **Seller / Vendor** | Hall owners, caterers, photographers, decorators | Creates a storefront, lists services, manages calendar, responds to inquiries, confirms bookings |
| **Admin (Platform)** | My team | Verifies vendors, handles disputes, manages payments, monitors quality |

## 4. How Each Service Type Works

### 4.1 Catering Centers

**How sellers list their services:**
- Create menu categories: Starters, Main Course, Desserts, Drinks, etc.
- Add each dish with:
  - Name and description
  - Photo
  - Base price
  - Serving size options (per 25, 50, 100, 150 persons)
  - Price auto-calculates based on quantity
- Can offer **fixed packages** (e.g., "Gold Menu — 10 dishes for 100 guests at PKR 85,000")
- Can offer **per-person pricing** with minimum guest count

**How users book:**
1. Browse caterer → view menu
2. Select dishes and enter guest count
3. **Live bill calculator** updates instantly
4. Can save as "My Menu" and compare with other caterers
5. Click "Request Quote" — sends exact menu + guest count to seller
6. Seller reviews and can:
  - Accept as-is
  - Send a custom quote (e.g., "If you swap beef biryani for chicken, I can do PKR 5,000 less")
  - Suggest alternatives
7. User accepts quote → pays deposit → booking confirmed

**Pricing transparency:** Users always see per-person cost breakdown. No hidden charges.

### 4.2 Marriage Halls / Venues

**How sellers list their services:**
- Upload photos (empty space, decorated events, lighting variations)
- Set capacity (minimum and maximum guests)
- Mark allowed event types: Mehendi, Barat, Walima, Corporate, Birthday, etc.
- Set pricing rules:
  - **Fixed price per event** (e.g., PKR 150,000 for any event)
  - **Per-person pricing** with minimum guarantee (e.g., PKR 800/person, minimum 150 guests)
  - **Time-based:** Lunch vs. Dinner rates
  - **Day-based:** Weekend surcharge
- Add amenities checklist: Parking, AC, Stage, Lighting, In-house Catering, etc.

**How users book:**
1. Search venues by city, date, guest count, event type
2. View venue storefront — see real photos, pricing, amenities
3. Select date → system checks availability instantly
4. If available, select:
  - Lunch or Dinner
  - Number of guests
  - Event type (from dropdown the venue allows)
5. **Auto-calculated estimate** appears immediately
6. User can "Hold This Date" (soft block for 48 hours) or "Request Quote"
7. Venue owner reviews and confirms
8. User pays deposit → date is hard-blocked on the calendar

**Availability logic:**
- If a date is confirmed booked, it shows **"Fully Booked"** but the venue still appears in search (grayed out) with next available dates suggested
- If seller marks a date as "Not Available" (personal event, renovation), it's blocked entirely
- Prevents double-booking with calendar sync

### 4.3 Photography

**How sellers list their services:**
- Create tiered packages:
  - **Silver:** 1 photographer, 4 hours, 200 edited photos
  - **Gold:** 2 photographers, 8 hours, 500 edited photos, highlight video
  - **Platinum:** Team of 3, full day, drone, same-day edit, album
- Add à-la-carte add-ons: Drone footage, extra hours, photo album, video teaser
- Show portfolio by event type

**How users book:**
1. Browse photographer → view packages and portfolio
2. Select package + add-ons
3. Enter event date and duration
4. See total price instantly
5. "Check Availability" → if free, request quote
6. Same negotiation/confirmation flow as above

### 4.4 Decoration Services

**How sellers list their services:**
- Upload **theme galleries:** Floral, Royal, Minimalist, LED, Traditional
- Set pricing by:
  - Room/area size
  - Per-table decoration
  - Fixed theme package
- List what's included: Flowers, drapes, lighting, stage, entrance

**How users book:**
1. Browse themes → save favorites
2. Select theme + venue size
3. Get estimate
4. Can request customization ("I want this theme but in maroon instead of red")
5. Quote and confirmation flow

## 5. The Booking & Reservation System

This is the heart of the platform. I don't want instant payments for everything — our market isn't ready for that. Instead, I'm using a **tiered commitment system** that protects both sides.

| Stage | What Happens | Payment |
|-------|-------------|---------|
| **1. Inquiry** | User sends detailed request (date, guests, services needed) | Free |
| **2. Hold** | Seller approves inquiry → date is **soft-blocked for 48 hours** | Small hold fee (2-3%) OR free for trusted users |
| **3. Quote Accepted** | User accepts seller's final quote | **Deposit paid (20-25%)** — held in escrow |
| **4. Confirmed** | Seller marks "Confirmed" → date is **hard-blocked** | Deposit released to seller after cooling period |
| **5. Pre-Event** | Final guest count and details confirmed | Remaining balance due 7 days before event |
| **6. Post-Event** | Event completed successfully | Final payment released to seller 24 hours after event |

**Why escrow matters:** Users don't trust sending PKR 100,000 to a stranger. Holding payment until the event is done builds massive trust. If the seller cancels, the user gets a full refund + help finding a backup.

**Double-booking protection:**
- Once a date is "Confirmed" or "Hold," it shows unavailable to other users
- Seller dashboard flashes **red alerts** if they try to confirm overlapping bookings
- Calendar sync prevents human error

## 6. Chat & Negotiation System

I originally thought of open chat bargaining like WhatsApp, but that's messy. Instead, I'm building a **structured negotiation flow**:

1. User sends a "Quote Request" with all details pre-filled (menu items, guest count, date)
2. Seller receives a structured request — not a vague "how much?" message
3. Seller can:
  - Accept the request as-is
  - Send a **counter-offer** with line-item changes ("Swap mutton karahi for chicken, save PKR 3,000")
  - Suggest a package upgrade or downgrade
4. Counter-offers have a **24-hour expiry** — creates urgency without pressure
5. User accepts, rejects, or counters back
6. Once agreed, both parties tap "Lock In" and the deposit stage begins

**In-platform messaging** is available throughout, but it's organized by booking — not a free-for-all chat. Every conversation is tied to a specific event plan.

## 8. Ratings, Reviews & Trust

Reviews only unlock **after the event date has passed**. No fake pre-booking reviews.

**Review structure:**
- Overall star rating (1-5)
- Category ratings: Quality, Value for Money, Communication, Punctuality
- Written feedback (min 50 characters)
- **Photo upload:** "Share a photo from your event" — this becomes powerful social proof
- **Verified Booking badge** on every review

**Seller response:** Sellers can reply publicly to any review. Professional responses to negative reviews actually increase trust.

**Trust badges for sellers:**
-  **Top Rated** (4.8+ stars, 50+ reviews)
-  **Quick Responder** (avg response under 2 hours)
-  **Verified** (platform team has validated their business)
-  **Premium Partner** (higher placement, stricter quality standards)
-  **New** (first 30 days on platform)

## 10. Additional Features I'm Building

### 10.1 Compare Tool
Users can select up to 3 vendors of the same type and see a **side-by-side comparison table**: price, rating, capacity, amenities, response time. This is a conversion game-changer.

### 10.2 Guest Count Flexibility
For catering, users enter a range (e.g., "80-100 guests") and see pricing for both extremes. Final headcount can be adjusted up to 72 hours before the event without penalty.

### 10.3 Bundle Booking
Users can book **Venue + Catering + Decoration** from different sellers as a single "Event Package." The platform coordinates between vendors. I take a slightly higher commission on bundles, but users get convenience and potential discounts.

### 10.4 Emergency Backup System
If a seller cancels last-minute, the platform instantly suggests **verified alternatives** with a small discount. This turns a disaster into a trust-building moment.

### 10.5 Event Checklist
Once a user starts planning, they get an auto-generated checklist:
- "Book photographer by [Date]"
- "Finalize guest count by [Date]"
- "Make final payment by [Date]"
- "Confirm seating arrangement 3 days before"

This keeps users engaged and reduces no-shows.

### 10.6 Multi-Event Support
A user might be planning a full wedding: Mehendi, Barat, and Walima. They can create **separate event plans** under one account and book different vendors for each.

### 10.7 Guest List Manager (Future)
Eventually, users can import guest lists, send digital invites, and track RSVPs — making EventConnect the full event OS.

## 11. Revenue Model

| Revenue Stream | Details |
|---------------|---------|
| **Commission per booking** | 8-15% of confirmed booking value (industry standard: 5-20%) |
| **Featured listings** | Sellers pay to appear at the top of search results |
| **Premium seller subscriptions** | Monthly fee for advanced features: analytics, priority support, higher photo limits |
| **Payment processing fee** | Small percentage on transactions (covers escrow and payment gateway costs) |
| **Bundle commission** | Slightly higher take rate on multi-vendor packages |

**No listing fees for the first 6 months** — I need to build the supply side. Once we have critical mass, we can introduce tiered plans.

## 12. Seller Onboarding Flow

I want a caterer or hall owner to go from signup to live in **under 10 minutes**.

1. **Sign up** with phone number + business name
2. **Select category:** Venue / Catering / Photography / Decoration / Multiple
3. **Upload verification:** CNIC + business registration (or utility bill for home-based)
4. **AI-guided setup:** "Let's add your first service" — step-by-step wizard
5. **Upload 5 photos** of your best work
6. **Set 3 available dates** to activate
7. **Go live** — profile visible, marked "New" for 30 days

**Verification timeline:** 24-48 hours for manual review. Verified sellers get a badge and higher search ranking.
